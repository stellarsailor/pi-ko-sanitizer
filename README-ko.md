# pi-ko-sanitizer

[English](README.md) | **한국어**

한국어 답변에 섞여 나온 중국어와 일본어 단어를 한국어로 바꾸는 [Pi](https://pi.dev) 확장입니다. 답변을 만든 뒤 일부 표현을 교정하며, 문장 전체를 번역하거나 특정 문자를 무조건 지우지 않습니다.

```
문서에 使用된 용어를 확인하세요 → 문서에 사용된 용어를 확인하세요
표의 页面을 열어 주세요 → 표의 페이지를 열어 주세요
```

## 설치

Node.js 22.19.0 이상이 필요합니다.

```bash
pi install npm:pi-ko-sanitizer
pi -e npm:pi-ko-sanitizer
```

이 확장은 `message_end`에서 동작합니다. 한자 독음 변환기를 함께 쓰는 경우 원문을 인식할 수 있도록 이 확장을 먼저 불러오세요.

## 동작 방식

- **사전 교정은 기본으로 켜져 있습니다.** 모델을 호출하지 않고 로컬에서 처리합니다. 구간 전체를 해석할 수 있을 때만 바꾸고, 일부 한국어 조사도 고칩니다. 한글 단어 끝에 붙은 짧은 일본어 가나도 한글로 바꿀 수 있습니다.
- 사전 교정은 코드, URL, 일본어 문장, 한자 병기, 사용자가 질문한 용어를 건드리지 않습니다. 확신하기 어려운 표현은 지우지 않고 그대로 둡니다.
- **모델 교정은 실험 기능이며 기본으로 꺼져 있습니다.** 사전으로 해석할 수 없는 구간의 교정 표현을 현재 모델에 물어봅니다. 답변을 새로 만들지 않고, 허용된 표현만 원문에 반영합니다. 자연스러워 보이지만 뜻이 다른 표현을 고를 수 있습니다. 시간이 초과되거나 응답을 쓸 수 없으면 사전 교정 결과를 유지합니다.

## 설정

| 환경 변수 | 기본값 | 동작 |
|---|---|---|
| `PI_KO_SANITIZER_LLM` | 꺼짐 | `1`이면 교정 대상이 있는 첫 번째 텍스트 부분을 현재 모델에 보냅니다. |
| `PI_KO_SANITIZER_LLM_TIMEOUT` | `12000` | 모델 교정 제한 시간입니다. 단위는 밀리초입니다. |
| `PI_KO_SANITIZER_VERIFY` | 꺼짐 | `1`이면 교정 제안을 확인하기 위해 모델을 한 번 더 호출할 수 있습니다. 맞는 표현도 거절할 수 있습니다. |
| `PI_KO_SANITIZER_OFF` | 꺼짐 | `1`이면 교정과 로그 기록을 모두 끕니다. |
| `PI_KO_SANITIZER_DEBUG` | 꺼짐 | 추가 진단 로그를 켭니다. |
| `PI_KO_SANITIZER_LOG_TEXT` | 꺼짐 | `1`이면 감지된 표현의 원문을 로컬 진단 로그에 남깁니다. 기본값에서는 원문 대신 해시를 남깁니다. |

`/zh-ko`로 세션별 집계와 로컬 로그 경로를 볼 수 있습니다. 민감한 대화에서는 원문 기록을 끈 상태로 두세요. 원격 모델로 모델 교정을 켜면, 수정하지 않을 내용까지 포함해 선택된 텍스트 부분 전체가 모델 제공자에게 전송됩니다.

## 개발

```bash
npm ci
npm run typecheck
npm test
```

테스트는 가상의 예시와 모의 모델 응답을 사용합니다. 대화 전문, 검색 기록, 실제 세션에서 수집한 프롬프트, 진단 로그는 커밋하지 마세요. 사전 처리 코어는 Pi에 의존하지 않습니다. `src/sanitize.ts`와 `src/rewrite.ts`를 참고하세요. 코어를 위한 별도 npm 진입점은 제공하지 않습니다.
